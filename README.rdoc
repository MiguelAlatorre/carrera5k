# Carrera 5K: Race Management System

A web application built for a coding competition hosted by Grupotres (2015). The brief was a website for a charity 5K race that benefits a children's home (casa hogar). Our team built a system that lets organizers create new races every year instead of a single static page.

**Demo video:** [https://www.youtube.com/watch?v=uaS-sO_nSvY]

## What it does

- Organizers add future races to the database, so the same system can run the event each year.
- Each race route is drawn on a map by connecting markers placed with the Google Maps API.
- Runners register for a race through the site.
- A payment screen exists on the front end only. The payment processing was left out because it needed information from the client that we did not have.

## Built with

- Ruby on Rails
- Google Maps API (the 2015 version)
- HTML, CSS and JavaScript
